# NavItem

One destination in the sidebar, with an optional count.

- The active page gets `aria-current="page"`, a 3px `copper` marker on the left and `body-strong` weight.
- `count` is mono and `ink-subtle`; `countTone="crit"` turns it into a `crit-soft` chip (firing alerts).
- Group items under `overline` section labels: MONITOR, DATA, OPERATE.
- Labels are nouns in sentence case: "Consumer groups", not "Groups Management".
