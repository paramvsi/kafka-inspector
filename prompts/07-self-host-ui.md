## Tasks
1. `AgentClient` implementing the full `KafkaClient` over REST + WebSocket (reconnect with backoff, resubscribe, stale-data dimming via the Disconnected state). Shape-compatible with `SimulatedClient`; run the same hook tests against a mocked agent (MSW).

3. Self-hosted chrome: sidebar variant (no Chaos, no "Run on your own Kafka", version + read-only chip), topbar without "Simulated cluster".
4. Read-only everywhere (20): banner on pages with write actions, disabled buttons with tooltip, no Produce/Create/Reset/Delete entry points reachable by URL either.
5. Clusters (14) in agent mode: read-only list from `/api/clusters` with "edit the config to change" note; cluster switcher drives `c=` in URLs.
6. Run on your own Kafka (19, demo only): form → generate `docker-compose.yml`, `.env` with variable **names only**, and a `docker run` line; Copy + Download zip (client-side, e.g. `fflate`). Security/SASL options per F-96. Nothing leaves the browser (assert no network calls in a test).
7. End-to-end: generate a compose file from the page, run it against the dev compose Kafka, sign in, see data (scripted in CI with Docker if feasible; else document as a manual check).
